## 2. 시스템별 UI 화면 특징

### 2.1 MES

- **실시간 현장 KPI**: OEE, 가동률, 다운타임, 수율, 작업지시 진행률을 한 화면에 색상 코딩으로 표시.
- **Role-based Shopfloor UI**: 오퍼레이터/감독자/품질 역할별로 다른 터미널·대시보드(Siemens Mendix 기반 등).
- **작업 중심 워크플로**: 작업지시 → 자재/문서 확인 → 실적 입력 → 품질 검사 → 전자서명 흐름.
- **Traceability**: Lot/Serial, eDHR, 비적합(NCR) 기록·이미지 첨부·도면 오버레이.
- **엣지/장비 연동 시각화**: PLC/IoT 데이터, 마이크로스톱, Andon 보드형 현황판.
- **Low-code 확장**: 벤더 기본 UI + Mendix/드래그앤드롭으로 현장 맞춤 화면 구성.

### 2.2 ERP (제조 모듈)

- **엔터프라이즈 디자인 시스템**: SAP Fiori Horizon 등 통일 컴포넌트·Floorplan·반응형 레이아웃.
- **역할/태스크 앱**: “모든 메뉴”가 아닌 구매·생산계획·재고 등 태스크 단위 앱.
- **임베디드 애널리틱스**: 트랜잭션 화면 안에 KPI 카드·차트 삽입.
- **Office 친화 UX**: 테이블·필터·엑셀형 그리드, 다크모드/접근성(고대비).
- **크로스 시스템 네비게이션**: ERP ↔ MES/PLM로 컨텍스트 유지 이동.

### 2.3 PLM

- **제품 구조(BOM) 트리 + 3D/CAD 뷰**: 좌측 구조, 우측 3D/도면 분할 뷰가 전형적.
- **변경관리(ECO/ECR) UI**: 영향 분석, 승인 워크플로, 협업 코멘트.
- **역할 기반 Navigate형 앱**: 전체 PLM 대신 “도면 보기”, “부품 목록”, “문제 보고” 등 경량 UI (Windchill Navigate).
- **드래그앤드롭·검색 중심**: 레거시 풀다운 메뉴에서 객체 중심 인터랙션으로 전환 (3DEXPERIENCE).
- **Digital Thread**: 설계 변경이 제조/품질 화면에 연결되는 상태 표시.

### 2.4 APS

- **인터랙티브 Gantt가 핵심**: 설비/라인 타임라인, 드래그로 일정 재배치, 제약 위반 하이라이트.
- **What-if / 시나리오 비교**: 계획 A/B 병치, KPI 델타(납기·가동률·재고).
- **부하·병목 히트맵**: 용량 대비 부하, 셋업/교체 최소화 시각화.
- **실시간 계획–실적 편차**: MES 실적 피드백으로 계획 이탈 알림.
- **모바일 알림 + Visual Analytics**: 플래너용 대시보드·3D 라인 뷰 증가 (2025 APS 트렌드).

### 2.5 FEMS / EMS

- **에너지 소비 시각화**: 전력/공조/조명/압축공기 등 용도별 실시간·히스토리 차트.
- **피크·수요반응(DR)**: 부하 제어, Peak levelling, 자동 Demand Response 상태.
- **지속가능성 KPI**: CO₂, 재생에너지 비중, ISO 50001 대응 리포트.
- **가젯형 대시보드**: Schneider PME처럼 위젯 조합으로 사이트/라인별 화면 구성.
- **설비–에너지 연계**: 생산량 대비 원단위(kWh/unit) 표시가 스마트팩토리와 결합되는 방향.

### 2.6 공통 UI 패턴 (전 시스템)

| 패턴 | 특징 |
|------|------|
| Overview → Drill-down | Level 1 현황 → Level 2 라인 → Level 3 설비 → Level 4 진단 |
| Status-first color | 정상은 중립색, 이상/알람만 색상 (ISA-101 High-Performance HMI) |
| Multi-device | 데스크톱 관제 + 태블릿/터치 터미널 + 모바일 알림 |
| Exception-based | “모든 데이터 나열”보다 이탈·알람·조치 필요 항목 우선 |
| Composable UI | 위젯/앱/템플릿 조립, Design System 기반 일관성 |

## 3. 글로벌 UI/UX 트렌드 상세 분석 (2025–2026)

### 3.1 인지부하 최소화와 High-Performance HMI의 주류화

전통적 “무지개색 P&ID 미믹”에서 **그레이스케일 베이스 + 이상 시에만 색상** 철학(ISA-101 / High-Performance HMI)이 SCADA·HMI뿐 아니라 MES 현황판·관제 대시보드로 확산되고 있다.

- 정상 상태는 시각적으로 조용하게, 이탈만 즉시 인지.
- Level 1–4 정보 계층으로 “한 화면에 모든 것”을 지양.
- 임베디드 트렌드(스파크라인)로 숫자만 보는 한계 보완.
- 현장 연구/가이드에서 **오퍼레이터 인지부하가 사무직 대비 매우 높다**는 점이 UX 우선순위의 근거.

**시사점**: 수집·설계 시 “예쁜 다크 대시보드”보다 **상황인식(Situational Awareness)과 알람 우선순위**가 품질 기준이 되어야 함.

### 3.2 Role-based · Task-based · Progressive Disclosure

SAP Fiori, Windchill Navigate, Siemens Opcenter Shopfloor UI 모두 **전체 시스템 노출 → 역할/태스크 앱**으로 이동.

- 2차 사용자(구매, 품질, 현장 작업자)는 경량 앱만 사용.
- Progressive disclosure로 상세는 드릴다운·슬라이드아웃·분할뷰에 배치.
- 교차 앱 SSO/컨텍스트 유지 네비게이션이 표준화.

**시사점**: 화면 카탈로그는 “모듈명”이 아니라 **Persona × Task × Device** 매트릭스로 정리하는 것이 글로벌 벤더와 정합.

### 3.3 Design System 기반 Enterprise Industrial UI

- SAP Fiori Horizon, AVEVA OMI 템플릿/그래픽 라이브러리, Ignition Perspective 컴포넌트 등 **디자인 시스템 + 재사용 오브젝트**가 필수.
- 멀티플랜트·멀티벤더 환경에서 UI 일관성이 교육비용·오류율에 직결.
- 웹 기술(브라우저 클라이언트, Linux 지원, 반응형)로 클라이언트 파편화 축소.

**시사점**: 커스텀 UI도 벤더 Design Token/컴포넌트 체계를 따르거나, 자체 Industrial Design System을 두는 방향.

### 3.4 Low-code / Composable MOM

Siemens(Mendix), Plex(Low-code orchestration), AVEVA(재사용 콘텐츠·OMI Apps)처럼 **현장 맞춤 화면을 코드 없이 조립**.

- 산업 템플릿(전자/프로세스/메디컬) 제공.
- 위젯·가젯·앱 마켓플레이스형 확장.
- “표준 코어 + 현장 확장 UI” 이중 구조.

**시사점**: 수집 화면을 “완성품 스크린샷”과 “조립 가능한 빌딩블록”으로 구분하면 재사용성 평가에 유리.

### 3.5 Real-time + Predictive + AI Assist

- MES/APS/SCADA가 단순 모니터링을 넘어 **예측 유지보수, 스케줄 추천, 이상탐지 알림**을 UI에 표면화.
- APS는 AI 최적화 엔진 + What-if + plan-vs-actual 편차 분석.
- AI 결과는 별도 리포트가 아니라 **기존 알람/작업 흐름에 임베드**(예: Level 2 오버레이 → CMMS 작업지시).

**시사점**: “설명 가능한 추천(왜 이 스케줄인가)”과 **사람 최종 판단 유지**가 UX 원칙으로 강조됨.

### 3.6 Digital Twin · 3D · Spatial Context

- AVEVA 3D Viewer/Map, APS 3D 라인 뷰, PLM CAD 동기화 등 **공간 컨텍스트**가 운영 UI에 진입.
- Digital Twin은 시뮬레이션·What-if·에너지/사이클타임 실험 후 현장 적용.
- 다만 ISA-101 관점에서는 **장식용 3D는 지양**, 상황인식에 기여할 때만 사용.

**시사점**: 3D는 PLM/레이아웃/대형 설비 관제에 우선, 단순 KPI 보드에는 2D High-Performance 그래픽이 더 적합.

### 3.7 Shopfloor Physical Context UX

제조 UX 특화 요구:

- 글러브·먼거리·밝은/어두운 조명 → 큰 터치 타깃, 고대비, 단순 탭 플로우.
- 레거시 PC/구형 하드웨어 성능 제약.
- 규제 산업(의약/항공) 전자서명·감사추적·검증(IEC 62366 등) UI.
- 다국어·교대근무·숙련도 편차 → 아이콘+텍스트 이중 코딩, 최소 교육.

**시사점**: 소비자 SaaS UX를 그대로 이식하면 실패. **현장 관찰(Contextual Inquiry)** 기반 설계가 글로벌 모범사례.

### 3.8 Sustainability · Energy as First-class UI

FEMS/EMS가 독립 시스템이 아니라 MES/관제 대시보드의 **1급 KPI**로 통합되는 추세.

- 생산 KPI와 에너지 KPI 병치 (원단위, 피크, CO₂).
- ISO 50001 리포트·감사 대응 화면.
- Demand Response·재생에너지 상태 시각화.

**시사점**: ESG/탄소 규제 대응으로 “생산–에너지–품질” 통합 Command Center UI 수요 증가.

### 3.9 Cloud SaaS · Browser · Mobile Continuum

- Opcenter X SaaS, 클라우드 MES, 브라우저 기반 SCADA/HMI로 **설치형 클라이언트 의존 감소**.
- 플래너·매니저는 모바일 알림/승인, 오퍼레이터는 고정 터미널 — **동일 디자인 시스템의 디바이스 적응**.
- 원격 협업·멀티사이트 Overview 대시보드(글로벌 포트폴리오 뷰).

### 3.10 Platform Convergence (Digital Thread UI)

PLM ↔ MES ↔ ERP ↔ APS ↔ FEMS 간 **컨텍스트 연속성**이 UI 경쟁력.

- 엔지니어링 변경 → 작업지시/품질계획 자동 반영 표시.
- 스케줄 변경 → 현장·에너지 부하 영향 즉시 시각화.
- 단일 Sign-on, 객체 ID 기반 deep link.

성숙 통합은 아직 소수(Tech-Clarity: 고성숙 약 1/5)이나, **UI 단의 “연결감”**이 벤더 차별점으로 부상.

## 5. 요약 인사이트

- 국외 제조 업무시스템 UI는 **“데이터 전시”에서 “상황인식·역할 기반 실행·예측 지원”**으로 이동 중.
- 시각 언어의 글로벌 표준 축은 **ISA-101 High-Performance HMI + Enterprise Design System(Fiori 등)**.
- 벤더 UI의 공통 DNA: **실시간 KPI, 드릴다운, 예외 중심, 멀티디바이스, Low-code 조립, Digital Thread 연동**.
- 차별화 축: **AI 추천의 설명가능성, Digital Twin/3D의 실용적 사용, 에너지·ESG KPI 통합, 현장 물리 맥락 UX**.
- 수집 링크는 공식 제품/블로그/인터랙티브 데모/YouTube/Behance/표준문서로 구성했으며, 상용 벤더는 전체 화면 갤러리보다 **데모·릴리즈 노트·디자인 가이드** 형태로 공개하는 경우가 많음.
