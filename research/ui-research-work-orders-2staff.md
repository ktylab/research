# infinitPINN UI 시안 — 기초자료 조사·분석 업무지시서

- **작성일**: 2026-07-24
- **목적**: Layer 3~4(MES/ERP/APS) 웹 UI 시안 제작을 위한 기초자료 수집·분석
- **선행 자료**: `research/layer34-web-uisystem-benchmark-kr-global.md`, `deliverables/SorTech_Layer34_UI_Benchmark.pptx`
- **인원**: 2명 (A: 벤치마크 수집 / B: 시안 설계 입력물 정리)
- **권장 기간**: 집중 조사 5영업일 + 공동 정리 1일 (일정은 팀 상황에 맞게 조정)

---

## 0. 공통 규칙 (두 명 모두)

1. **목표 화면 우선순위(1차 시안 6종)**만 깊게 판다.  
   `S01 포털` · `S02 Command Center` · `S04 Shopfloor` · `S05 그리드` · `S07 Gantt` · `S09 품질`
2. 자료를 “예쁘다/많다”가 아니라 아래 태그로 저장한다.  
   `시스템(MES/ERP/APS)` × `화면유형(Sxx)` × `사용자` × `디바이스` × `상호작용(Monitor/Execute/Plan/Approve)`
3. 저작권·보안: 공개 데모·마케팅·가이드만 사용. 고객사 비공개 화면은 수집 금지. 사내 공유 시 출처 URL 필수.
4. 산출물은 공유 폴더에 일일 업로드. 파일명 규칙:  
   `YYYYMMDD_역할_화면유형_출처요약.확장자`  
   예: `20260725_A_S07_SAP-PSB-gantt.png`
5. 매일 16:30 15분 스탠드업: 오늘 수집 건수 / 막힌 점 / 내일 우선순위.

## 2. 직원 A — 벤치마크 수집·UI 패턴 분석

### 2.1 미션
한국·글로벌 MES/ERP/APS **공개 UI**를 모아, 시안 디자이너가 바로 참조할 **패턴 카드**를 만든다.

### 2.2 조사 대상 (필수 / 선택)

**필수 (각 1개 이상 깊게)**
- 한국: 더존 Amaranth 10 포털, 영림원 K-System(MES/ERP), VMS MOZART 또는 Asprova Gantt, 미라콤/삼성SDS/LG CNS 공개 자료
- 글로벌: SAP Fiori(Launchpad·List Report·Object Page·Scheduling Board), Siemens Opcenter(Shopfloor/Quality), PlanetTogether 또는 DELMIA Ortems Gantt

**선택**
- Rockwell OEE 대시보드, AVEVA MES Web Portal, Aspen Schedule Explorer, ISA-101 High-Performance HMI 가이드

### 2.3 구체 할 일 (체크리스트)

- [ ] 선행 PPT의 S01~S12 정의 숙지 (30분)
- [ ] 1차 6종별 **레퍼런스 5개 이상** 수집 (스크린샷 또는 공식 이미지 + URL)
- [ ] 각 레퍼런스에 **패턴 카드 1장** 작성 (아래 템플릿)
- [ ] “좋은 점 / 따라하면 안 되는 점”을 화면유형별로 5줄 이내 요약
- [ ] 한국 vs 글로벌 **차이 관찰 노트** 1페이지 (결재·검색·그리드 밀도·Gantt 조작 등)
- [ ] Day 4에 B와 교차리뷰: B의 화면명세에 레퍼런스 ID 매핑

### 2.4 패턴 카드 템플릿 (복붙용)

### 2.5 산출물 목록
